# StickFighting

Оригинальный браузерный пиксельный 2D-файтинг: игрок против ИИ или против друга по сети, три бойца, три живые арены и матч до двух побед. Интерфейс полностью на русском языке.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Никакой игровой сервер, регистрация или база данных не нужны (в том числе для игры по сети: см. ниже).

Для проверки на телефоне в той же локальной сети:

```sh
npm run dev -- --host 0.0.0.0
```

Откройте на телефоне адрес компьютера и порт Vite, например `http://192.168.1.10:5173`. При необходимости разрешите соединение в локальном брандмауэре.

## Игра по сети

Играть можно вдвоём на разных устройствах: ПК, телефон, планшет. Отдельный сервер не нужен: **устройство, которое создаёт игру, само является сервером**. Оно ведёт бой и считает все удары, а второе устройство отправляет ему нажатия и показывает то, что происходит на арене. Соединение идёт напрямую между браузерами (WebRTC).

1. Оба игрока открывают эту же страницу игры (например, `npm run dev -- --host 0.0.0.0` на одном компьютере и адрес вида `http://192.168.1.10:5173` на втором устройстве, либо любой хостинг собранной версии).
2. Хост нажимает **По сети → Создать игру** и отправляет другу показанный код любым мессенджером (кнопки «Копировать код» и «Поделиться»).
3. Гость нажимает **По сети → Подключиться**, вставляет код хоста и получает ответный код. Его нужно отправить хосту.
4. Хост вставляет ответный код и нажимает **Подключить**. Когда соединение установится, оба оказываются в лобби.
5. В лобби каждый выбирает своего бойца (один и тот же боец двоим недоступен), хост выбирает арену и нажимает **В бой**. Хост играет левым бойцом, гость правым. Свой боец помечен «ТЫ». Управление то же, что и в игре против ИИ.

Что важно знать:

- Код действует для одной попытки соединения. Если не получилось, хост нажимает **Создать игру заново**, а гость **Попробовать заново**.
- Лучше всего работает в одной Wi-Fi сети: задержка обычно 5-30 мс, в углу экрана показан пинг. Через интернет соединение тоже устанавливается: используются публичные STUN-серверы Google и Cloudflare, чтобы устройства нашли друг друга. Без них (в закрытой сети) игра работает по локальным адресам. В остальное время к внешним серверам игра не обращается. Если у кого-то из игроков очень строгий NAT или мобильный оператор блокирует прямые соединения, потребовался бы TURN-сервер, которого здесь нет.
- Если сеть блокирует связь между устройствами (изоляция клиентов на гостевом Wi-Fi), соединение не установится: подключите оба устройства к обычной сети.
- Хост должен держать вкладку открытой и на виду: браузер замедляет скрытую вкладку, и бой у обоих остановится. Если хост свернул игру или связь пропала, у гостя появится предупреждение.
- Пауза (Esc) общая: её может поставить и снять любой игрок, бой останавливается у обоих. Настройки и справка в сетевом бою бой не останавливают. Автопауза при потере фокуса в сетевой игре отключена.
- После матча доступны **Реванш** (гость просит, хост запускает), **В лобби** (сменить бойца или арену, не переподключаясь) и **Выйти из игры**. Если соперник вышел или связь оборвалась, появится сообщение.

Как это устроено: хост единолично считает бой, гость каждые 1/60 с отправляет нажатия, а хост каждые 1/60 с присылает позиции бойцов, здоровье, анимации, звуки и частицы. Нажатия повторяются в нескольких пакетах подряд, поэтому потеря отдельных пакетов не теряет удары и не залипает клавиши. Если два удара приходятся на один и тот же кадр, выигрывает тот, чья очередь обрабатываться: она чередуется каждый кадр.

## Production

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Размещайте её на обычном статическом хостинге; внешние игровые ресурсы не требуются.

## Как играть

1. Нажмите **Играть** или Enter в главном меню.
2. Выберите бойца, арену и сложность, затем нажмите **В бой**.
3. После отсчёта `3, 2, 1, БОЙ!` победите в двух раундах.
4. После матча доступны **Реванш** с теми же параметрами и возврат в главное меню.

В каждом раунде 100 здоровья и 60 секунд. Победа присуждается за нокаут или большее оставшееся здоровье. При равном здоровье раунд переигрывается без начисления победы. Здоровье восстанавливается между раундами, накопленная энергия сохраняется. Возможны максимум три результативных раунда; ничьи не увеличивают номер раунда.

## Клавиатура

| Кнопка | Действие |
| --- | --- |
| Стрелки влево / вправо | Движение |
| Стрелка вверх | Прыжок |
| Стрелка вниз | Присесть |
| J | Быстрый удар рукой |
| K | Сильный удар рукой |
| U | Быстрый удар ногой |
| I | Сильный удар ногой |
| Вниз + K | Апперкот |
| Вниз + I | Подсечка |
| Вверх + I, либо I в воздухе | Удар ногой в прыжке |
| Двойное нажатие в сторону соперника + J | Рывок с ударом |
| Space (удерживать) | Блок |
| O | Спецприём: 50 энергии |
| Esc | Пауза / продолжить |

Используются физические коды клавиш: русская раскладка не мешает атакам. Бойцы автоматически поворачиваются друг к другу. Удержание кнопки атаки не повторяет удар: для нового удара нужно новое нажатие.

## Телефон

Сенсорные кнопки автоматически включаются на устройствах с основным сенсорным указателем. Их также можно включить вручную в **Настройках**. Слева движение и прыжок, справа четыре обычные атаки, спецприём и блок. Кнопки поддерживают несколько одновременных касаний и захват указателя. Блок нужно удерживать. Кнопки находятся под ареной и не закрывают бойцов.

Предпочтительна горизонтальная ориентация. В вертикальной показывается небольшая подсказка. Прокрутка и масштабирование отключены только во время боя. Полноэкранный режим доступен по кнопке в шапке, если его разрешает браузер. При потере фокуса или скрытии вкладки бой автоматически ставится на паузу.

## Бойцы и арены

- **Вихрь**: сбалансированный. Спецприём **Вихревой удар**: вращение и продвижение вперёд, 18 урона.
- **Искра**: более быстрая, обычные удары немного слабее. Спецприём **Разряд**: увеличенная дальность, краткое уклонение на старте, 16 урона.
- **Титан**: медленнее, обычные удары сильнее. Спецприём **Разлом**: подбрасывание соперника ударом по земле, 20 урона. От ударной волны можно уйти прыжком.

Арены: **Багровый перевал** (закатные горы), **Шёпот леса** (водопад) и **Над городом** (ночная крыша). В каждой пять графических слоёв, параллакс и фоновая анимация.

## Комбо и защита

Примеры: `J > J > K`, `U > U > I`, `вниз + K > J`. После подтверждённого попадания разрешена отмена восстановления в следующий совместимый приём. Ввод буферизуется на 180 мс. Комбо сбрасывается при блоке или через 1,2 секунды без попадания. После третьего удара действует постепенное снижение урона; восьмой удар отбрасывает противника и даёт ему 850 мс защиты от следующего попадания.

Блок полностью предотвращает обычный урон. Спецприём наносит через блок 2 урона. Попадания и полученный урон накапливают энергию до 100, спецприём стоит 50. Старт, активная фаза, восстановление, дальность и вертикальный хитбокс у каждого из девяти приёмов отдельные. Сильные попадания дают короткий hitstop и умеренную тряску, которую можно отключить.

ИИ принимает решения с задержкой, наблюдает начавшиеся атаки, а не ввод игрока. На лёгком уровне чаще ошибается, на сложном чаще блокирует и продолжает комбо.

## Звук и графика

Все арены и позы бойцов рисуются локально на Canvas в разрешении 480x270 и выводятся через Phaser 3 с nearest-neighbor масштабированием. Нет запросов к отсутствующим изображениям, аудиофайлам или внешним шрифтам.

Оригинальные удары, свист, блок, спецприёмы, отсчёт, нокаут и короткие формантные возгласы синтезируются Web Audio API. Звук удара и возглас запускаются только после реального попадания. Блок имеет отдельный звук, а промах - только тихий свист. AudioContext создаётся только после действия пользователя. Есть переключатель звука и громкость; настройки сохраняются локально. При отсутствии поддержки аудио игра остаётся доступной.

## Структура

- `src/App.tsx`: игровой цикл интерфейса, клавиатура, пауза, настройки.
- `src/components/GameUI.tsx`: пиксельный логотип, HUD, портреты, модальные окна и сенсорные кнопки.
- `src/components/Overlays.tsx`: выбор параметров матча и справка.
- `src/game/engine.ts`: фиксированная симуляция 60 Гц, хитбоксы, ИИ, комбо, раунды и эффекты. Работает в трёх режимах: против ИИ, хост (второй боец управляется по сети) и клиент (только показывает состояние хоста).
- `src/game/input.ts`: ввод одного бойца (клавиши, буфер ударов, рывок) и упаковка ввода гостя для отправки хосту.
- `src/game/protocol.ts`: формат сообщений сетевой игры.
- `src/game/net.ts`: WebRTC-соединение без сервера и коды подключения.
- `src/game/online.ts`: лобби, старт матча, реванш и связь сети с движком.
- `src/components/Online.tsx`: экраны «По сети» и лобби.
- `src/game/phaser.ts`: жизненный цикл Phaser и вывод пиксельной сцены.
- `src/game/art.ts`: оригинальные процедурные арены и все позы бойцов.
- `src/game/audio.ts`: локальный Web Audio синтезатор.
- `src/game/types.ts`: данные бойцов, арен, атак и типы.

Стек: React, TypeScript, Vite, Phaser 3, Tailwind CSS v4. Все персонажи, названия, графика и звуковые эффекты оригинальные.

## Ручная проверка

0. Сетевая игра: откройте игру в двух окнах браузера (или на двух устройствах), создайте игру в одном, подключитесь из другого, пройдите лобби и бой. Проверьте, что оба видят одно и то же, что гость управляет правым бойцом, что пауза общая и что при закрытии одного окна у второго появляется сообщение.

1. Начните матч на каждой арене и проверьте все девять приёмов из раздела управления.
2. Подойдите на дистанцию удара, соберите комбо, затем удерживайте блок; убедитесь в разнице звуков попадания, блока и промаха.
3. Накопите 50 энергии, используйте O и проверьте расход энергии.
4. Завершите матч до двух побед, начните реванш, откройте паузу и вернитесь в меню.
5. Проверьте громкость, отключение звука и сохранение настроек после перезагрузки.
6. На телефоне проверьте движение вместе с атакой, блок, поворот устройства и отсутствие прокрутки во время боя.
